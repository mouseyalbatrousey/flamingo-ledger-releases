# Flamingo Ledger releases

Installers and update files for **Flamingo Ledger**, desktop accounting software that keeps
your books in a company file on your own computer and works fully offline.

Download the latest Windows installer from [Releases](../../releases/latest)
(`Flamingo-Ledger-Setup-<version>.exe`). Installed copies check here for updates on their own.

This repository holds releases only; there is no source code here.

Flamingo Ledger is in early testing. Keep your current accounting system running alongside it
for now.

**Windows may warn about the installer.** It isn't code-signed yet, so SmartScreen says
"Windows protected your PC". Choose *More info*, then *Run anyway*.
